================================================================
 GigaAM Voice Typer  -  голосовой ввод для Windows
================================================================

Локальная диктовка русской речью в любое текстовое поле Windows
по горячей клавише. Без интернета (после первой установки),
без облака, всё работает на вашем компьютере.

Модель: GigaAM v2 RNNT int8 (Сбер, отличное качество русского)
Распознавание идёт через ONNX Runtime + DirectML (для AMD/Intel
iGPU) с автоматическим fallback на CPU.

----------------------------------------------------------------
ТРЕБОВАНИЯ
----------------------------------------------------------------
- Windows 10 или 11, x64
- ~3 ГБ свободного места на диске (Python + пакеты + модель)
- Микрофон
- Интернет на время УСТАНОВКИ (~700 МБ скачивания)

----------------------------------------------------------------
ПЕРЕНОС НА ДРУГОЙ КОМПЬЮТЕР
----------------------------------------------------------------
ВАЖНО: НЕ копируйте папку .venv на другой ПК! Она привязана к
конкретному пути установки Python. Если случайно скопировали -
ничего страшного, setup.bat обнаружит это и пересоздаст .venv.

Лучший способ:
- На исходном ПК: запустите pack_for_share.bat -> получится
  GigaAM-Voice-Portable.zip (без .venv, ~30 КБ)
- На целевом ПК: распакуйте zip, запустите setup.bat

----------------------------------------------------------------
ПЕРВАЯ УСТАНОВКА  (один раз на каждом компьютере)
----------------------------------------------------------------
1) Скопируйте всю эту папку (или распакуйте zip) в любое место,
   например C:\Tools\GigaAM-Voice-Portable

2) Двойной клик на  setup.bat
   Подождите 5-15 минут. Скрипт:
   - проверит/поставит Python 3.12 (через winget)
   - проверит/поставит Visual C++ Redistributable
   - создаст виртуальное окружение в .venv
   - скачает все Python-пакеты (~500 МБ)
   - скачает модель GigaAM v2 (~240 МБ)
   - прогреет модель (первый инференс)

   Если в конце увидите "Установка завершена" - всё готово.

3) Если в setup.bat будет ошибка про winget - поставьте Python 3.12
   вручную с https://www.python.org/downloads/ (галочка
   "Add Python to PATH" обязательна), затем повторно запустите setup.bat

----------------------------------------------------------------
ЗАПУСК
----------------------------------------------------------------
- start_silent.vbs   - запуск в фоне (без окна), РЕКОМЕНДУЕТСЯ
- start.bat          - запуск с консолью (видно лог в реальном
                       времени, удобно для отладки)
- add_autostart.bat  - сделать так, чтобы программа стартовала
                       автоматически при входе в Windows
- remove_autostart.bat - убрать из автозапуска
- stop.bat           - остановить работающий фоновый процесс
- uninstall.bat      - полное удаление окружения и (опц.) модели

----------------------------------------------------------------
КАК ПОЛЬЗОВАТЬСЯ
----------------------------------------------------------------
1) Запустите start_silent.vbs (или start.bat для отладки).
   Через 3-5 секунд в системном трее появится зелёный кружок
   (если не видите - откройте панель скрытых иконок стрелочкой).

2) Кликните в любое текстовое поле в любой программе:
   браузер, Word, Telegram, IDE, командная строка - где угодно.

3) Зажмите  Ctrl+Win  - услышите "пип", кружок станет красным
   и пульсирующим, в нём цифра текущей длительности записи.

4) Говорите.

5) Отпустите Ctrl+Win - "пип" вниз, кружок станет синим
   (распознавание идёт, обычно 0.5-2 сек), затем "пип" вверх -
   распознанный текст вставится в курсор автоматически.
   Кружок снова станет зелёным.

----------------------------------------------------------------
ИКОНКА В ТРЕЕ
----------------------------------------------------------------
Зелёный            ожидание
Красный с цифрой   идёт запись (цифра = секунды)
Синий              идёт распознавание / вставка

Правый клик на кружке - меню:
- Открыть лог  (показать voice_typer.log)
- Выход        (корректно завершить)

----------------------------------------------------------------
ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
----------------------------------------------------------------
1) Хоткей Ctrl+Win не реагирует:
   - Запустите start.bat от админа (правый клик -> Run as admin).
     Это нужно если в системе есть другая программа с админ-
     правами, перехватывающая ввод.
   - Альтернатива - в start_silent.vbs тоже можно сделать
     запуск с админ-правами через планировщик задач.

2) Распознаёт криво / не тот микрофон:
   - Проверьте дефолтный микрофон в Параметрах Windows.
     Программа использует системный input по умолчанию.

3) Во время записи кружок не пульсирует:
   - Откройте voice_typer.log в Notepad - там будут ошибки.

4) Программа молча падает:
   - Запустите через start.bat вместо start_silent.vbs -
     увидите traceback в окне.

5) "Окружение не найдено" / нет .venv:
   - Запустите setup.bat ещё раз. Если падает на установке
     пакетов - проверьте интернет и/или права на запись в эту
     папку.
